# 📚 Data Structures & Algorithms in Java — Semester 3

> A personal learning repository containing my **Data Structures & Algorithms implementations, Java programs, university coursework, and textbook exercises** from my 3rd semester of Software Engineering.

---

## 📖 About

This repository documents my journey learning **Data Structures & Algorithms (DSA) using Java** during my **3rd semester of Software Engineering**.

The implementations and exercises come from three main sources:

* 🎓 **University coursework** — concepts and programs covered in my 3rd-semester Data Structures & Algorithms course
* 📖 **Y. Daniel Liang** — concepts and exercises from *Introduction to Java Programming and Data Structures*
* 🧪 **Personal practice** — implementations and experiments that reinforce concepts and improve problem-solving skills

Rather than keeping these programs scattered across different locations, this repository brings them together into one organized collection that can be continuously updated throughout the semester.

It also serves as a **reference for other students** who are learning Data Structures & Algorithms with Java.

---

## 🧭 Progress

### ✅ Covered

The following topics are currently implemented in the repository:

* Binary tree construction and representation
* Preorder, inorder, postorder, and level-order traversals
* Basic binary tree operations: search, size, height, and leaf detection
* Binary tree metrics: node count, sum, height, and diameter
* Undirected graphs using an adjacency matrix
* Adding vertices and edges to a graph

### 🚧 In Progress

The following topics are currently in progress:

* AVL trees: insertion, height maintenance, and tree rotations
* Binary tree equality and full-tree checks

Additional topics will be added progressively as they are covered through university coursework and self-study.

The `graph/` and `trees/` directories contain the current graph and tree implementations.
